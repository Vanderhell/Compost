# Captured experiments

These directories contain captured research and experimental runs. They are
intentionally versioned and are not source-code build artifacts. A run can
include world state, telemetry, reference input, prepared FOOD, organism state,
or other reproducibility data. Directory names preserve the historical
iteration or diagnostic label; they do not by themselves establish a scientific
conclusion.

## 1m runs

| Directory | Historical label / observable purpose |
| --- | --- |
| `1m/baseline` | Baseline captured 1m run. |
| `1m/bounded` | Bounded-run iteration. |
| `1m/diagnosed` | Diagnostic iteration; captured telemetry records a structural-material-conservation failure. |
| `1m/final` | Unknown / historical iteration labelled `final`. |
| `1m/final2` | Unknown / historical iteration labelled `final2`; captured telemetry records a structural-material-conservation failure. |
| `1m/fixed` | Historical iteration labelled `fixed`; captured telemetry records no failure. |
| `1m/invariant` | Invariant-check iteration; captured telemetry records a structural-material-conservation failure. |
| `1m/ledger` | Activity-ledger diagnostic iteration; captured telemetry records a structural-material-conservation failure. |
| `1m/trace` | Trace diagnostic iteration; captured telemetry records a structural-material-conservation failure. |
| `1m/world-fixed` | Historical world-fix iteration; captured telemetry records no failure. |
| `1m/real-sandbox` | Captured real-sandbox 1m run. |
